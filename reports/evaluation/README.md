# Evaluation report status

`current/` is the only active persisted-model verification output. It is
generated by `python scripts/evaluate_persisted_models.py` from the authoritative
release manifest, checked-in model metadata, artifact hashes, and golden
predictions executed through the production model registry.

`superseded/legacy_liver_diabetes_evaluation_2026-07-25/` contains the complete,
byte-preserved evaluation bundle that pre-dated the current five-model release.
It must not be cited as evidence for current models.

The archived bundle describes a Liver Random Forest and Diabetes SVM evaluated
on recreated row-level splits. Current persisted Liver and Diabetes artifacts
are Logistic Regression pipelines with different metadata and artifact hashes.
The historical metrics cannot be mapped to the released artifacts, and the
recreated splits are not accepted as authoritative release evidence.
