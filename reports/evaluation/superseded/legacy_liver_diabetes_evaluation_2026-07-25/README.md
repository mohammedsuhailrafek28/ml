evidence and must not be used in product claims, documentation, or releases.

persisted artifacts are Logistic Regression pipelines. The original script also
recreated stratified row-level splits instead of consuming the split evidence
stored with the released artifacts. Consequently, these results cannot be
reliably mapped to the authoritative release manifest.
