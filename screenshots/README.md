# Medical AI Suite — Product Screenshot Gallery

This gallery documents the production-like Medical AI Suite interface for researchers and technical reviewers. All displayed measurements are synthetic public-dataset fixture values; no patient or user-submitted data is included.

Capture date: 2026-10-06 (Asia/Calcutta)  
Branch: `feature/premium-clinical-ui`  
Commit: `4da52a00aea869f1cb8f820721ead21aadcc4fd0`  
Desktop viewport: 1440 × 1000  
Mobile viewport: 390 × 844

Medical limitation: every result shown here is an educational/research output, not a diagnosis, screening result, triage decision, treatment recommendation, or disease probability. Parkinson's is explicitly **Experimental** and uses pre-computed voice biomarkers with weak subject-disjoint holdout evidence.
