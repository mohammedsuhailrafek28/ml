# Medical AI Suite 0.9.0-rc.1

Status: educational/research release candidate. Intended for technical review,
education, and reproducibility work only. It is not a diagnosis or screening
service, has no clinical validation, and must not guide care. All scores are
uncalibrated estimator outputs, not disease probabilities. Parkinson's remains
Experimental. Operational health and local load measurements do not establish
clinical validity, deployment availability, or a production availability SLO.

This candidate pins the verified Python 3.11.15 and Node 20.19.0 base-image
index digests, although OS package repository contents remain time-varying build
inputs. It packages the existing persisted-model release without changing
model bytes, datasets, preprocessing, feature order, thresholds, evaluation
metrics, or golden expected values. The application release manifest binds the
application identity to selected dependency, Dockerfile, model-release, and
generated-contract hashes. The source revision is runtime-injected and reduced
to a safe hexadecimal revision token.

The Compose example publishes only the frontend on loopback; FastAPI and its
protected Prometheus endpoint remain on an internal network. Service credentials
are mounted at runtime as a Compose secret and are not user accounts. The rate
limiter remains process-local; there is no end-user identity system, distributed
rate limiter, centralized monitoring, TLS termination, or measured deployed
availability SLO. Distributed rate limiting and centralized monitoring remain
future work.
