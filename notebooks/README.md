# Notebooks — historical / exploratory only

These `*_analysis.ipynb` notebooks are **exploratory data analysis from before the
disease-by-disease ML upgrade**. They are **not** part of the production training
path and are **not** the source of any shipped metric.

The authoritative, reproducible training code is:

| Disease | Trainer |
| --- | --- |
| Liver | `src/training/train_liver.py` |
| Heart | `src/training/train_heart.py` |
| Diabetes | `src/training/train_diabetes.py` |
| Kidney | `src/training/train_kidney.py` |
| Parkinson's | `src/training/train_parkinsons.py` (subject-aware) |

Run all: `python -m src.training.train_all`. Every metric in `models/*/metadata.json`
and `reports/final_results_summary.*` is generated by those scripts.

The notebooks may show pre-upgrade splits, feature handling and numbers that no
longer match production. Treat them as a lab notebook, not documentation.
`jupyter` is an optional dev dependency (`requirements-dev.txt`).
